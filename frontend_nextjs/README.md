# Elegant Hello World – Next.js

A sophisticated Hello World interface with a centered animated card, modern typography, smooth transitions, and a tasteful light theme using custom colors.

## Tech
- Next.js App Router
- TypeScript
- Tailwind CSS v4 (via `@tailwindcss/postcss`)
- Inter font from Google Fonts

## Theme
- Primary: `#1e293b`
- Secondary: `#64748b`
- Accent: `#22d3ee`
- Light theme with soft shadows and gradient accents.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view.

## Edit
- Global styles: `src/app/globals.css`
- App layout: `src/app/layout.tsx`
- Page: `src/app/page.tsx`

## Notes
- The UI includes smooth entrance animation, floating accent glow, gradient borders, and responsive spacing.
- No environment variables are required.
